# 打包说明（Windows / macOS）

「搬山」用 PyInstaller 打包成独立可执行文件，用户无需安装 Python，双击即用。

## 重要：打包不含任何数据

打包**只包含代码 + 界面静态资源**，**绝不包含**你的账号凭据、任务记录、登录缓存：

- `data/config.json`（网盘 Cookie / 令牌）
- `data/tasks.db`（迁移任务库）
- `data/edgeprof`、`data/.tylogin-profile`（天翼登录浏览器缓存）

运行时数据写到**用户目录**（见 `panmigrate/config.py` 的 `DATA_DIR`）：

| 系统 | 数据目录 |
|---|---|
| Windows | `%APPDATA%\panmigrate` |
| macOS | `~/Library/Application Support/panmigrate` |
| Linux | `~/.local/share/panmigrate` |

所以打出来的 exe/app 是「干净」的，不含任何账号信息，可以放心分发。

---

## 打包步骤

### 前提

- 装好 Python 3.10+，并 `pip install pyinstaller`
- PyInstaller **不支持跨平台交叉打包**：Windows 的 exe 要在 Windows 上打，macOS 的 app 要在 Mac 上打

### Windows

双击 `build_win.bat`，或手动执行：

```bat
python -m pip install --upgrade pyinstaller
python -m PyInstaller panmigrate.spec --noconfirm
```

产物：`dist\搬山.exe`（单文件，约 10MB）

### macOS

在 Mac 上执行同样两条命令（`panmigrate.spec` 跨平台通用）：

```bash
python3 -m pip install --upgrade pyinstaller
python3 -m PyInstaller panmigrate.spec --noconfirm
```

产物：`dist/搬山`（单文件可执行文件，约 10MB）

> macOS 上首次打开会提示「无法验证开发者」，右键 → 打开，或在
> 系统设置 → 隐私与安全 → 点「仍要打开」即可。

---

## 产物使用

1. 双击 `搬山.exe`（Windows）或 `搬山`（Mac）
2. 会自动打开默认浏览器，进入 `http://127.0.0.1:8899`
3. 关闭：在控制台窗口按 `Ctrl+C`，或直接关掉窗口

> 默认保留控制台窗口（能看到日志、方便停止）。若想做成「无窗口纯后台」，
> 把 `panmigrate.spec` 里的 `console=True` 改成 `console=False` 重新打包。

---

## 已知外部依赖

打包后的程序仍依赖**本机已有的外部环境**（不会打进 exe，因为它们不是 Python）：

- **Edge / Chrome 浏览器**：天翼「一键登录」需要（Windows 10/11 和 macOS 通常已内置 Edge/Safari，Mac 上需装 Chrome 或 Edge）
- **Node.js**：天翼「一键登录」用它读浏览器登录态（若不用天翼一键登录，则不需要）

其它三家（百度/阿里/夸克）的扫码、Cookie 登录不依赖任何外部程序。

## 环境变量（可选）

| 变量 | 作用 |
|---|---|
| `PANMIGRATE_HOME` | 覆盖数据目录位置 |
| `PANMIGRATE_NO_BROWSER=1` | 启动时不自动打开浏览器 |
