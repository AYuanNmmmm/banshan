## 搬山 v1.26.0

把文件从一个网盘搬到另一个网盘：本机中转、分片直传、断了能续，凭据只留本机。

**支持**：百度网盘 · 阿里云盘 · 夸克网盘 · 天翼云盘 · 115 网盘 · 123 云盘，六家任意方向互迁。

### 功能

- 单机运行：本地 HTTP 服务 + 系统浏览器作界面，不打包浏览器内核
- 分片直传：读一块传一块，整文件不落本地磁盘；进度写 SQLite，关掉再开接着传
- 抽样校验：比对大小 + 首/中/尾内容，不做全文件哈希
- 断点、限速、失败重试、导出 CSV 报告
- 自选文件与文件夹，目标端可新建目录
- 浅色 / 深色两套皮肤
- 网页登录：Chrome/Edge 走 CDP，macOS 可用 Safari（WebDriver）

### 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon） | `banshan-macOS-arm64-v1.26.0.zip` — 解压得到 `搬山.app`，双击启动；右上角「退出」结束进程 |
| Windows（x64） | `banshan-windows-x64-v1.26.0.exe` — 双击即用，单文件便携 |

macOS 首次打开若提示「无法验证开发者」：右键 → 打开，或到「系统设置 → 隐私与安全性」点「仍要打开」。

想自己打包：macOS 用 `bash build_mac.sh`，Windows 用 `build_win.bat`（需先装 PyInstaller）。

### 数据位置

凭据（Cookie / token）只写在本机：macOS 是 `~/Library/Application Support/panmigrate`，
Windows 是 `%APPDATA%\panmigrate`，源码运行则是项目内 `data/`。不上传任何服务器。

### 注意

- 基于各家网盘的非公开接口，平台一改就可能失效
- 百度开放平台认证只能访问 `/apps/` 下的专属文件夹，所以默认用扫码登录（可读全盘）
- 115 写入为整文件上传，单文件上限 500MB
- 请只迁移自己的文件，遵守各网盘服务条款
