## 搬山 v1.26.0 · 首次开源

把文件从一个网盘搬到另一个网盘：本机中转、分片直传、断了能续，凭据只留本机。

### 支持

百度网盘 · 阿里云盘 · 夸克网盘 · 天翼云盘 · 115 网盘 · 123 云盘 —— 六家**任意方向**互迁。

### 这一版有什么

- **单机运行**：纯 Python 标准库起本地服务，界面交给系统浏览器，不打包浏览器内核
- **分片直传**：读一块传一块，整文件不落本地磁盘；SQLite 记进度，关掉再开接着传
- **抽样校验**：传完比对大小 + 首/中/尾内容，不做全文件哈希（省一半流量）
- **双主题**：浅色 / 深色，跟着系统偏好走，也可手动切
- **断点与限速**：可暂停、可限速，暂停 1 秒内生效
- **自选文件**：目录树里勾文件或整个文件夹，也能贴路径批量加入；目标端可新建文件夹
- **失败重试 / 导出报告**：失败任务一键重试，迁移清单可导出 CSV
- **网页登录三条通道**：Chrome/Edge 走 CDP；macOS 可选 Safari（WebDriver）；百度/阿里/夸克扫码
- **253 个单元测试**，覆盖传输引擎、各家适配器、登录态判定、任务库、路由

### 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `banshan-macOS-arm64-v1.26.0.zip` | 解压得到 `搬山.app`，双击启动；界面右上角「退出」结束进程 |
| Windows | 自行打包 | 本 Release 暂未附带（上一版 exe 与本次源码不一致，不混发）。在 Windows 上执行 `build_win.bat` 即可 |

macOS 首次打开若提示「无法验证开发者」：右键 → 打开；或到「系统设置 → 隐私与安全性」里点「仍要打开」。

### 数据与隐私

账号凭据（Cookie / token）只写在本机数据目录：macOS 是 `~/Library/Application Support/panmigrate`，
Windows 是 `%APPDATA%\panmigrate`，源码运行则是项目内 `data/`。不上传任何服务器。

### 注意

- 全部基于各家网盘的**非公开接口**，平台一改就可能失效
- 百度开放平台认证只能访问 `/apps/` 下的专属文件夹，所以默认给的是扫码登录（能读全盘）
- 115 写入是整文件上传，单文件上限 500MB
- 请只迁移自己的文件，遵守各网盘服务条款
