# 搬山 · 换电脑部署说明

目标：把这个工具拷到**任何一台 Windows 电脑**上，双击就能用，不用装任何环境。

---

## 一、目标电脑需要什么

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位） |
| 浏览器 | 系统自带的 **Edge** 就行（要用天翼「一键登录」时必须有） |
| 磁盘 | 约 50 MB（程序本体 ~18 MB + 运行解压的临时文件） |
| 网络 | 能访问各家网盘 |

## 二、**不需要**装什么（重点）

- ❌ 不需要装 Python
- ❌ 不需要 pip / 任何第三方库
- ❌ 不需要装 Node.js（早期版本天翼登录要用，现已改为纯 Python 实现）
- ❌ 不需要装数据库、不需要管理员权限

`搬山.exe` 是单文件程序，Python 运行时、二维码库、网页界面全部打包在里面了。

---

## 三、两种用法，按需选

### 方式 A：普通使用（数据存在本机用户目录）

```
把 搬山.exe 复制到新电脑任意位置 → 双击
```

数据会自动存到：

```
%APPDATA%\panmigrate\
├─ config.json      账号、登录态、迁移设置
├─ tasks.db         任务清单与断点续传进度
└─ panmigrate.log   运行日志（排查问题时看这个）
```

**换电脑时想保留登录态和进度**：把上面整个 `panmigrate` 文件夹拷到新电脑的同一位置即可。

### 方式 B：便携模式（数据跟着程序走，推荐 U 盘/多机使用）

```
新电脑上建一个文件夹，例如 D:\搬山\
├─ 搬山.exe
└─ panmigrate-data\        ← 手动建这个空文件夹（或从旧电脑拷过来）
```

只要 `搬山.exe` **旁边**存在 `panmigrate-data` 文件夹，程序就会把所有数据写进它里面，
不再碰 `%APPDATA%`。

好处：把整个 `D:\搬山\` 拷到 U 盘，插到任何电脑上双击就能接着传，
**账号登录态、已传进度全都在**，不用重新扫码。

> 顺序是：`PANMIGRATE_HOME` 环境变量 > 便携文件夹 > `%APPDATA%\panmigrate`。

## 四、首次使用流程

1. 双击 `搬山.exe`，会自动弹出浏览器（默认 `http://127.0.0.1:8899`）
2. 左边选**源**网盘，右边选**目标**网盘
3. 各自点登录：
   - 百度 / 阿里 / 夸克：点「扫码登录」，手机 App 扫一下确认
   - 天翼：点「一键登录」，会弹出一个**受控浏览器窗口**，在里面登录天翼官网，
     登录成功后窗口自动关闭、自动填好登录态
4. 点「浏览」勾选要传的文件 → 加入清单
5. 点「开始迁移」

> 小技巧：登录成功后，两块登录面板会**自动收起**，把版面让给文件列表。
> 想改设置时点右上角「展开」就行。

## 五、常见问题

**双击后提示「Windows 已保护你的电脑」**

这是 SmartScreen 对所有未签名 exe 的默认提示。点「更多信息」→「仍要运行」。

**双击后没反应 / 浏览器没弹出来**

看任务栏有没有多一个命令行窗口。若提示端口被占用，程序会自动换端口并照常打开浏览器
（控制台里会打印实际地址，形如 `http://127.0.0.1:52341`）。

**杀毒软件报警**

程序会启动本地服务（只监听 `127.0.0.1`，不对外开放）并读写自己的数据目录，
这些行为可能被误判。加入信任即可。

**天翼「一键登录」报「没找到 Edge/Chrome」**

装一个 Edge（Win10/11 一般都自带），或者在该电脑上改用「网页 Cookie」方式登录。

**天翼一键登录一直停在「等待登录」**

在弹出的浏览器窗口里完成登录（手机号/密码或短信验证码）。登录成功后会自动识别，
大约 1~2 秒内关闭窗口。如果窗口被关掉，程序会立刻提示「浏览器窗口已关闭」。

**换电脑后不想重新扫码**

用方式 B，把 `panmigrate-data` 一起拷过去。或者用方式 A 时手动拷 `%APPDATA%\panmigrate`。

**想让程序在后台跑、不弹浏览器**

命令行执行：`搬山.exe --port 8899`，并设环境变量 `PANMIGRATE_NO_BROWSER=1`。

## 六、给维护者：重新打包

```bat
:: 在项目根目录
python -m PyInstaller panmigrate.spec --noconfirm
:: 产物在 dist\搬山.exe
```

打包前跑一遍测试：

```bat
python -W ignore::ResourceWarning -m unittest discover -s tests -t .
```
